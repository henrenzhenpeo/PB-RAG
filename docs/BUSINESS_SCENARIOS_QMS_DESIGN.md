# PB-RAG 业务场景：QMS 质量排查与设计协同核查

> 状态：场景与验收设计，尚未实现场景数据集或完成 Agent 实测。场景取材于项目发起人简历中的伯恩光学 QMS 与四方协同平台经历；演示数据必须自行编造或使用获准脱敏的材料，不复制企业内部文档、设备记录、图纸或客户数据。本文不把 PB-RAG 原型能力表述为原工作项目的既有交付。

## 共用能力与实施边界

两组场景使用同一 PB-RAG Runtime、Workspace/知识库作用域、文档版本、检索阶段、Run/Step/Tool Execution、引用和评测机制。先使用 Markdown 与普通文本 PDF，文档中的“设备状态”“项目当前配置”只作为带版本的演示快照；没有只读业务接口时，系统不得声称读取了实时状态。用户明确选择固定 RAG 问答或 Agent 调研，首期不依赖自动意图路由。

Agent 只调用 `search_knowledge`、`read_document` 和必要时的 `calculator`。报告按“问题范围、分项发现、逐项来源、冲突或缺口、建议核对事项”组织；建议是辅助核查，不代替质量处置或设计审批。每条可核实事实绑定文档版本、Chunk 与稳定来源位置。来源不足时说明已检查范围并停止推断。外部业务工具、MCP、Skill、写操作和多 Agent 不属于这两个首期闭环。

## 场景 A：QMS 质量异常排查

**问题：**质量工程师面对某机台的重复报警，需要同时查设备操作规范、报警处置手册和质量异常流程。一次检索可能只命中其中一份资料，无法判断各文档是否相互支持或存在版本冲突。

**演示语料：**虚构机台 A-17 的报警代码说明、操作规范 v1/v2、异常升级流程和一份脱敏的历史案例摘要。至少设计一处版本变更、一处文档冲突和一处缺失的实时设备数据。若引入报警日志，首期只能作为注明采集时间的文档快照。

**固定 RAG 问题：**“A-17 的 E42 报警按当前操作规范应先检查什么？”答案应来自当前文档版本，附准确引用；无明确条款时拒答。

**Agent 调研任务：**“A-17 连续出现 E42 时，操作规范、报警手册和质量流程分别要求什么？这些资料能否确认根因，下一步应由谁核对？”Agent 分解子问题、多轮检索、定点阅读，区分处置步骤、流程要求、历史案例与尚未证实的根因。报告不能把历史案例当成当前机台事实。

**验收：**至少引用两份不同文档的当前版本；能指出相互冲突或缺失的条款；无实时数据时明确不能确认当前机台状态或根因；Run 轨迹可解释每次搜索和阅读；用相同语料比较固定 RAG 与 Agent 在跨文档任务上的正确性、引用、延迟与成本。

## 场景 B：设计协同资料核查

**问题：**设计人员需要核对项目图纸模板、标准字体与设计规范是否一致。规范知识和项目资料处于不同来源，且“模板存在”并不能证明“当前项目正在使用该模板”。

**演示语料：**虚构项目 D-204 的项目资料快照、图纸目录与模板版本清单、标准字体说明、设计规范 v1/v2 和一份模板变更记录。快照注明生成时间、来源和版本；不放入真实图纸或客户信息。

**固定 RAG 问题：**“当前规范对图纸标题栏字体有什么要求？”只回答文档明示的规范，附版本引用。

**Agent 调研任务：**“D-204 资料快照所列图纸模板和字体，与当前设计规范是否一致？还有哪些资料不足以完成核查？”Agent 分别查规范、模板清单和项目快照，逐项比对并给出依据；如果快照没有实际字体字段，只能标为待核验，不能断言合规。

**验收：**报告把规范要求与项目快照事实分列，逐项标注来源版本和时间；能识别过期模板、缺失字段与相互冲突记录；没有实时项目接口时不称“当前线上配置已核实”。

## 交付顺序与评测

1. 先用 QMS 场景完成 `search_knowledge`、`read_document`、跨文档报告与故障验收，它最贴近现有 RAG 资源链。
2. 复用同一 Runtime 接入设计协同的静态项目快照，验证跨来源事实和规范结论的区分，不新增业务工具。
3. 两组数据分别形成版本化 manifest、文档版本、问题、期望证据、拒答/缺口标签；记录 Prompt、模型、工具、代码与配置版本。评测覆盖单文档、跨文档、冲突、旧版本和无证据题。
4. 只有静态快照无法满足已定义任务且有可用的安全数据源时，再按 ADR 0009/0010 设计受治理的只读项目或设备查询工具，补作用域、时效、超时、审计和对照评测。是否接入 MCP 由独立实验决定。

## 简历与演示边界

原工作项目的职责和成果以可核实的简历与实际工作记录为准。PB-RAG 演示可说明“基于 QMS/设计协同经验抽象场景，独立实现并评测知识调研 Agent”，但不得把新原型的恢复、引用、评测或跨文档报告写成原企业系统已上线能力。质量、成本和速度数字只引用已发布的版本化评测报告。
