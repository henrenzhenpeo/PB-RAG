# PB-RAG 学习考察与记录

> 当前题库基于 2026-11-22 的已实现代码和验证事实。它考察设计、代码定位、失败语义和证据意识；未实现的知识工具只考察方案，不当成已有能力。

各题的代码对应参考答案见 [学习考察参考答案](LEARNING_QUESTION_ANSWERS.md)。正式考察请先独立回答，再打开答案复盘。

## 节奏与记录方法

- 每周一次正式考察，建议 30～45 分钟；每次从当前阶段选 4～6 题，至少包含一道故障题和一道代码定位题。
- 每次先独立作答，再对照代码、测试、ADR 和评测报告复盘。回答应标明“代码已实现”“有实测证据”或“设计方案”。
- 每题 0～4 分：0 未答或关键事实错误；1 能说出名词；2 能说明主路径；3 能解释约束与失败路径并定位代码；4 能提出可执行验证及可复现证据。总分按题目数归一到 100 分。
- 记录到下方表格：日期、代码提交、题号、得分、证据位置、薄弱点、下次复查。未作答不得预填分数；历史记录追加在本文件，不写入 `HANDOFF.md`。
- 下周优先复查得分低于 3 的题；新功能完成后添加对应题目，并明确代码位置和验收证据。
