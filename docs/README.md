# PB-RAG 文档索引

本目录只保存需要跨任务维护的项目文档。代码注释描述局部实现，提交记录描述历史变化；不要把聊天流水或逐次修复日志复制进文档。

## 新任务阅读顺序

1. [项目上下文](PROJECT_CONTEXT.md)：稳定目标、范围、架构与工程原则；
2. [协作规则](RULES.md)：注释、编译和功能文档同步规则；
3. [六周路线](ROADMAP_6_WEEKS.md)：里程碑、工作内容和验收标准；
4. [当前交接](HANDOFF.md)：当前阶段、已验证能力、风险和下一步；
5. 与任务相关的 ADR、Prompt 或评测资料。

## 文档职责

| 类型 | 位置 | 保留内容 | 不应包含 |
| --- | --- | --- | --- |
| 项目入口 | `README.md` | 项目简介、当前进度摘要、技术栈、运行方式 | 详细架构决策、修复流水 |
| 稳定上下文 | `PROJECT_CONTEXT.md` | 长期目标、范围、稳定架构、系统边界 | 临时进度、单次验证结果 |
| 协作规则 | `RULES.md` | 注释、编译和功能文档同步约束 | 架构设计、当前进度、具体实现流水 |
| 执行计划 | `ROADMAP_6_WEEKS.md` | 六周里程碑和验收标准 | 每日完成记录 |
| 当前状态 | `HANDOFF.md` | 当前事实、验证、风险、下一步 | 已失效的历史修复列表 |
| 架构决策 | `adr/` | 问题、候选、决定、影响与验证 | 可随意改写的当前进度 |
| 运行时 Prompt | `../prompts/` | 版本化模型指令及管理规范 | 权限或安全的唯一实现 |
| 评测资料 | `../evaluation/` | 版本化语料清单、数据集和可复现报告 | 无数据支撑的效果结论 |

## 维护规则

- 稳定决策变化：更新 `PROJECT_CONTEXT.md`，必要时新增或替代 ADR；
- 里程碑变化：更新 `ROADMAP_6_WEEKS.md`；
- 完成实质实现：只在 `HANDOFF.md` 保留最新状态、验证、风险和下一步；
- Prompt 实质变化：增加版本，并在固定数据集上评测；
- 效果或性能结论：在 `evaluation/` 保存可复现报告，再从交接文档链接；
- 过时说明先合并到对应权威文档，再删除，避免多个文件维护同一事实。
