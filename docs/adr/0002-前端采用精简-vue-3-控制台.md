# ADR 0002：前端采用精简 Vue 3 控制台

- 状态：已接受
- 日期：2026-10-27
- 影响文档：`docs/PROJECT_CONTEXT.md`、`docs/ROADMAP_6_WEEKS.md`、`docs/HANDOFF.md`、`docs/PB-RAG企业级Agent工程实战方案.md`、`docs/WEKNORA_项目拆解与Agent产品路线图.md`

## 背景

PB-RAG 的演示需要让人看见入库状态、引用、检索阶段、Agent 步骤、审批和评测对比。WeKnora 的 Web 前端是 Vue 3、TypeScript、Vite 单页应用，用 TDesign、Pinia、axios 和 SSE 完成知识库、对话与引用。它同时包含嵌入页、桌面端、多语言、组织、设置中心和工具箱。

六周版本的界面目标是把核心机制展示清楚。页面数量不构成项目价值。

## 问题

第一期前端应该先做一份脱离业务的调试页，还是做一套能走完演示路径的 Vue 应用？如果做 Vue 应用，应该复用 WeKnora 的哪一层？

## 约束

- 每周建议投入 20～30 小时，界面工作不能挤占 Agent、RAG、权限、评测和失败处理。
- 权限的最终判断在 Spring Boot。前端路由只决定进入哪一页。
- 文档内容、模型输出和工具结果按不可信数据处理后再渲染。
- 进度落后时可以减少页面，不能去掉入库状态、引用和失败原因的可见性。

## 候选方案

1. 只用 HTTP 客户端或单个调试页查看接口。启动快，但第 6 周的演示脚本缺少连续界面。
2. 按 WeKnora 的 `/platform` 复制完整控制台，包括嵌入、桌面端、多语言、组织和设置中心。对照细致，六周内会把时间花在外围产品上。
3. 采用与 WeKnora 相同的 Vue 3 技术骨架，只保留演示主路径上的页面。

## 决定

采用方案 3。

### 技术骨架

- Vue 3、TypeScript、Vite、Vue Router。
- Pinia 只保存当前 Workspace、当前会话和进行中的流。
- 普通请求使用 axios。聊天和 Agent 运行使用 `@microsoft/fetch-event-source` 消费 SSE。
- 答案用 Markdown 渲染，并在写入页面之前消毒。
- 组件库使用 TDesign，便于对照 WeKnora 的页面结构。
- 开发时由 Vite 将 `/api` 代理到 Spring Boot。

### 页面

| 路由 | 作用 | 进入时间 |
|---|---|---|
| `/login` | 登录并选择 Workspace | 第 4 周与权限一起完成；此前可用固定 Workspace |
| `/workspaces/:id/knowledge-bases` | 知识库列表 | 第 1 周 |
| `/workspaces/:id/knowledge-bases/:kbId` | 上传、解析阶段、失败原因和重试 | 第 1 周 |
| `/workspaces/:id/chats/:chatId` | 流式回答、引用，以及向量、关键词、融合和重排结果 | 第 1 周回答与引用；第 2 周补检索阶段 |
| `/workspaces/:id/runs/:runId` | Run/Step、工具参数、审批、取消和终态 | 第 3 周，审批在第 4 周 |
| `/workspaces/:id/evaluations` | 两次评测运行的对比 | 第 5 周 |

对话页和运行页使用同一布局：左侧是消息或步骤，右侧是引用、检索阶段或审批。

### 明确不做

网页嵌入、Wails 桌面端、多语言、组织与邀请、全局命令面板、设置中心、工具箱、Wiki、Office 在线预览。

## 理由

WeKnora 值得对照的是「知识库 → 上传状态 → 流式对话 → 引用」这条信息路径，以及 SSE 与后端事件的对应关系。PB-RAG 还需要把检索中间结果和 Agent 步骤直接放在页面上，因为项目要解释运行机制。

TDesign、Pinia 和 fetch-event-source 与 WeKnora 一致，读它的 `frontend/src/router`、`api` 和聊天流处理时可以直接映射。产品表面保持在演示路径内。

## 负面影响

- 界面不能代表完整企业控制台。
- TDesign 带来一套组件约定；不因此复制 WeKnora 的主题、图标离线方案和设置分区。
- 第 1 周如果页面铺开超过知识库详情和对话，后端纵向切片会被拖慢。

## 后续验证

- 第 1 周可以在页面上完成上传、查看任务阶段、收到流式回答并打开引用原文。
- 第 2 周对话页能看到各检索阶段的中间结果。
- 第 3 周运行页能回放每一步工具调用，并在页面上取消运行。
- 第 4 周越权操作在界面上表现为失败，且前端隐藏按钮不能绕过后端拒绝。
- 第 6 周按演示脚本在这些页面上走完闭环。
