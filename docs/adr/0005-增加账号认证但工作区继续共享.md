# ADR 0005：增加账号认证，工作区暂时共享

- 状态：已接受
- 日期：2026-11-09
- 覆盖：ADR 0004 中“首期不实现用户与登录”的决定

## 背景

工作区选择页需要真实账号入口和个人资料。现有 Workspace 没有 owner、成员关系或权限表，直接把路径中的 Workspace ID 当成授权判断是不成立的。

## 决定

- 支持邮箱注册、密码登录、退出和本人显示名称修改；
- 密码使用 PBKDF2-HMAC-SHA256 加随机盐存储；服务端保存会话令牌的 SHA-256，浏览器持有 HttpOnly、SameSite=Lax Cookie，会话有效期七天；
- `/api/**` 除注册和登录外要求有效会话；修改请求要求自定义请求头，以阻止普通跨站表单提交；
- 所有已登录用户暂时共享全部 Workspace 和资料。界面明确说明这一点；当前没有成员关系与 Workspace 权限隔离；
- 后续如需多用户隔离，先设计 owner、成员关系和资源访问策略，再在 HTTP、检索与工具执行前统一校验。

## 风险与后续

开放注册适合受控开发部署，不适合直接对公网开放。上线前需要注册开关或邀请机制、登录限流、密码重置及会话清理。认证与迁移仍需真实 PostgreSQL 集成测试。
