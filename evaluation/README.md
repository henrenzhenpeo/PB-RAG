# PB-RAG 评测索引

本目录保存可复现的评测输入和报告，不保存临时接口响应、密钥或聊天记录。评测结论必须同时说明数据集、语料版本、模型、检索配置和代码版本。

## 当前基线

- 语料清单：[retrieval-v1-manifest.json](corpus/retrieval-v1-manifest.json)，冻结 4 个文档版本和 377 个 Chunk；
- 数据集：[retrieval-v1.jsonl](datasets/retrieval-v1.jsonl)，包含 32 条可回答问题和 8 条不可回答问题；
- 权威报告：[retrieval-v1 全量基线与 Top 30/60 对照](reports/retrieval-v1-baseline-2026-11-19.md)。

早期 8 条可回答、3 条不可回答的人工抽样只用于发现 Rerank 门槛和证据充分性问题。其有效结论已经合并到正式报告，不再单独维护。

## 目录职责

| 目录 | 内容 | 维护要求 |
| --- | --- | --- |
| `corpus/` | 参与评测的文档版本、Chunk 和状态清单 | 文档版本或索引变化时生成新版本或更新哈希 |
| `datasets/` | 一行一个 JSON 对象的人工真值 | 保持稳定 ID，证据绑定文档版本、Chunk 和来源位置 |
| `reports/` | 可复现的运行配置、指标、失败分析和结论 | 新实验覆盖旧结论时明确对照，不保留无独立价值的临时抽样 |

## 报告最低信息

- 数据集与 manifest 的版本或 SHA-256；
- Git commit、日期、执行入口和并发方式；
- Embedding、Rerank、Chat 模型与可获得的实际版本；
- Vector/BM25/Fusion/Rerank/Context 的 Top-K、门槛和预算；
- Recall@K、MRR、拒答语义、错误率、P50/P95/最大延迟；
- 失败样本的阶段定位，以及是否由相同数据集回归；
- Token、费用或无法获得这些数据的明确限制。

## 使用边界

- 小样本烟测只能发现问题，不能宣称整体质量提升；
- 不可回答问题需要检查最终回答语义，不能只看是否召回候选；
- 远程模型的单次延迟受网络和供应商抖动影响，性能结论必须使用可比较的重复运行；
- 数据集、Prompt、模型或配置发生实质变化时，不能沿用旧报告的准入结论。
